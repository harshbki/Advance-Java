# ShopSphere

RTU Advanced Java e-commerce project. This repository follows the supplied project guide.

## Build order
1. Requirements, use cases, and UI screen plan (`docs/requirements.md`)
2. MySQL schema and ER diagram (`database/`)
3. Java models and JDBC DAOs
4. Service layer and MVC web application
5. Authentication, sessions, filters, and listeners
6. JSP, EL, JSTL, reusable fragments, and tags
7. Complete the core customer/admin shopping flow
8. Add syllabus demonstrations: Socket, RMI, Swing, serialization, JNDI, and i18n
9. Test, document, and prepare viva materials

## Modules
- `web/`: Jakarta Servlet + JSP customer and admin application
- `database/`: MySQL schema and seed data
- `swing-admin/`: desktop administration module
- `network/`: `java.net` client/server demonstration
- `rmi/`: remote inventory service
- `docs/`: requirements, diagrams, setup, and project report

The project guide recommends completing the core web flow before the additional syllabus demonstrations.
